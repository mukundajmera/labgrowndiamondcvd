# WooCommerce Product Setup Template
## Lab Grown Diamond CVD - Product Configuration Guide

**Purpose**: Standard template for creating diamond products with consistent formatting and complete specifications.

---

## Product Naming Convention

**Format**: `[Carat] Carat [Shape] Lab Grown Diamond - [Color]/[Clarity] - [Certification]`

**Examples**:
- `1.50 Carat Round Lab Grown Diamond - D/VVS1 - IGI Certified`
- `2.00 Carat Princess Lab Grown Diamond - E/VS2 - GIA Certified`
- `1.25 Carat Cushion Lab Grown Diamond - F/VS1 - IGI Certified`

---

## SKU Format

**Format**: `LGDC-[SHAPE]-[CARAT]-[COLOR]-[CLARITY]-[SEQUENCE]`

**Shape Codes**:
- RD = Round
- PR = Princess
- CS = Cushion
- EM = Emerald
- OV = Oval
- PE = Pear
- HT = Heart
- MQ = Marquise
- RA = Radiant
- AS = Asscher

**Examples**:
- `LGDC-RD-150-D-VVS1-001`
- `LGDC-PR-200-E-VS2-002`
- `LGDC-CS-125-F-VS1-003`

## Product Images Checklist

### Required Images

1. **Featured Image** (Main product photo)
   - Resolution: Minimum 1500x1500px
   - Format: JPG or PNG
   - View: Front view showing diamond from top
   - Background: Pure white (#FFFFFF)
   - File size: Under 300KB (after optimization)

2. **Gallery Images** (4-8 images minimum)
   - Image 1: Top view (table view)
   - Image 2: Side view (profile/pavilion)
   - Image 3: Angled view showing brilliance
   - Image 4: Certificate image (full report)
   - Image 5: Scale reference (diamond on hand or with ruler)
   - Image 6: Close-up of facets
   - Image 7: Certification logo/seal
   - Image 8: Packaging (optional)

### Image Specifications
```
Minimum Resolution: 1500x1500px (for zoom functionality)
Recommended: 2000x2000px
Maximum File Size: 500KB per image (compress with Smush)
Format: JPG (photos) or PNG (with transparency)
Color Space: sRGB
Background: Pure white preferred
Lighting: Soft, even lighting to show true color
```

### Image Naming Convention
```
Format: sku-view-number.jpg

Examples:
lgdc-rd-150-d-vvs1-001-top-view.jpg
lgdc-rd-150-d-vvs1-001-side-view.jpg
lgdc-rd-150-d-vvs1-001-certificate.jpg
```

## Pricing Guidelines

### Price Calculation Factors

**Base Price Elements**:
1. Carat weight (primary factor)
2. Color grade
3. Clarity grade
4. Cut quality
5. Certification type
6. Market positioning

**Suggested Pricing Formula** (adjust based on market):
```
Base Price = [Carat Weight] × [Color Factor] × [Clarity Factor] × [Cut Factor] × [Base Per Carat Rate]

Color Factors:
D: 1.20
E: 1.15
F: 1.10
G: 1.05
H: 1.00
I: 0.95
J: 0.90

Clarity Factors:
FL: 1.30
IF: 1.25
VVS1: 1.20
VVS2: 1.15
VS1: 1.10
VS2: 1.05
SI1: 1.00
SI2: 0.95

Cut Factors:
Excellent: 1.10
Very Good: 1.05
Good: 1.00
Fair: 0.95
```

### Competitive Pricing
- Research competitor pricing for similar diamonds
- Position 10-20% below mined diamond equivalents
- Offer bundle discounts for multiple purchases
- Create tiered pricing for wholesale customers
